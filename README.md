# 🏏 RCB IPL Performance Analysis

## 📌 Project Overview
This project analyzes Royal Challengers Bangalore (RCB) IPL performance using SQL, Python, and Power BI. The objective is to uncover insights related to batting performance, strike rates, match phases, boundary analysis, and advanced cricket metrics.

---

## 🎯 Project Objectives
- Analyze RCB batting performance
- Identify top run scorers
- Calculate strike rates
- Perform phase-wise analysis (Powerplay, Middle Overs, Death Overs)
- Create advanced cricket metrics
- Build an interactive Power BI dashboard

---

## 🛠 Tools & Technologies
- PostgreSQL (DBeaver)

- Power BI

---

## 🔍 Key Insights
- Virat Kohli emerged as the leading run scorer.
- Rajat Patidar emerged as the leading six hitter.
- Devdutt Padikkal emerged as the one of the powerful aspect for the team.
- RCB scored most aggressively during death overs.
- Boundary percentage significantly increased after over 15.
